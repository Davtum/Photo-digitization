# Проверка по снимкам заказчика с измеренными размерами: протокол (предрегистрация)

План 3, задача 27; спецификация, п. 12 и п. 13 («первые цифры точности»).
**Зафиксирован до получения результатов; отступления — в конце, с датой и причиной.**

Статус: протокол, формат таблицы и скрипт готовы; **снимки заказчика не получены**.

## 1. Что это и чем это не является

Это **первые цифры точности** на нескольких реальных фасадах — не проверка
статистического допуска п. 2.2: для неё нужна полевая кампания с эталоном (план 3,
«что оставляет открытым»). Скрипт печатает это первой строкой, отчёт — первым
абзацем.

## 2. Что нужно от заказчика

По каждому фасаду:

1. **Снимки** — исходные файлы с камеры/дрона, с EXIF, без обработки и без
   пересжатия; желательно профиль калибровки камеры (`docs/operator-quickstart.md`,
   п. 4).
2. **Измерения** рулеткой или лазерным дальномером, с указанием прибора и его
   погрешности:
   - **опорная база** — один размер в плоскости стены, как можно длиннее (например,
     ширина простенка или цоколя между углами), и какие точки на фасаде его концы;
   - габариты (ширина, высота) проёмов по **наружной кромке** стены — не менее 10
     проёмов на фасад;
   - заглубление окна (от плоскости стены до плоскости рамы/четверти) у тех же
     проёмов, где доступно;
   - по возможности — положения нижних левых углов проёмов от начала отсчёта
     (первый конец базы).
3. **Схема** — фото или эскиз фасада, где измеренные проёмы подписаны (например,
   «2 этаж, 3-е слева»), чтобы их можно было сопоставить с разметкой.

## 3. Формат таблицы измерений

CSV, UTF-8, разделитель запятая; столбцы:

| Столбец | Значение |
|---|---|
| `image` | имя снимка без расширения — как `<снимок>.json` экспорта |
| `element_id` | идентификатор проёма в экспорте (`w_000`, …); у базы — пусто |
| `quantity` | `width`, `height`, `recess`, `x`, `y`, `base` |
| `value_mm` | измеренное значение, мм |
| `sigma_ref_mm` | погрешность измерения, мм |
| `is_base` | `1` у одной строки на снимок — размера, ставшего опорной базой; иначе `0` |
| `note` | подпись проёма по схеме заказчика |

Пример:

```csv
image,element_id,quantity,value_mm,sigma_ref_mm,is_base,note
DJI_0412,,base,8420,3,1,простенок 1 этажа между углами
DJI_0412,w_000,width,1460,2,0,1 этаж 1-е слева
DJI_0412,w_000,height,1910,2,0,1 этаж 1-е слева
DJI_0412,w_000,recess,150,5,0,1 этаж 1-е слева
```

`element_id` заполняет оператор после разметки — по схеме заказчика и подписям
проёмов в окне.

## 4. Процедура

1. Оператор (обученный, задача 24) размечает снимок в окне; **опорная база —
   ровно тот размер, что отмечен `is_base = 1`**, длина и погрешность — из таблицы.
2. Проёмы размечаются по инструкции, все измеренные; экспорт JSON.
3. Оператор заполняет `element_id`, **не видя** остальных измерений таблицы (второй
   человек сводит таблицу).
4. `python scripts/verify_measured.py измерения.csv <снимок>.json …`

## 5. Анализ (зафиксирован до получения результатов)

- **Опорная база в проверку не входит**: она задаёт масштаб, и её сравнение с собой
  замкнуло бы проверку; таблица без строки базы — отказ скрипта.
- Раздельно: **габарит**, **положение**, **глубина**, и по режимам (`assisted`/`auto`).
- `error_stats`: RMSE, P95, **смещение отдельно от разброса**.
- Покрытие интервалов 1σ и 2σ (норма 68 % и 95 %) **вместе со средней σ**
  (`mean_sharpness`): покрытие без остроты завышается раздутой σ. σ интервала —
  `√(σ_модели² + σ_измерения²)`.
- Interval score (п. 12.3).
- Величины, которые конвейер не выпустил (глубина при невидимой грани, положение без
  σ), перечисляются с причиной, а не выбрасываются молча.
- При n < 30 в группе вывод помечается «мало для статистики».

## 6. Как читается результат (зафиксировано до получения)

- Смещение габарита больше σ измерения рулеткой — систематика (кромка, база,
  калибровка), разбирается по снимкам до всякой статистики.
- Покрытие 2σ заметно ниже 95 % при малой средней σ — σ занижена; выше 95 % при
  большой σ — σ раздута. Оба случая — вход для задачи 25 и бюджета п. 6.1.
- Цифры по габариту сравниваются с целью п. 2.2 (1σ ≤ 10 мм в `assisted`) только как
  ориентир.

## 7. Инструментарий и его проверка

`scripts/verify_measured.py`; тесты `tests/test_verify_measured.py`: синтетическая
сцена с тремя проёмами через конвейер, «измерения» из истины сцены, строка базы
исключается, группы раздельно, таблица без базы — отказ.
