# Правка разметки: замер полного пересчёта (план 3, задача 16)

Правка точки (перетаскивание в режиме «Навигация») пересчитывает **все** элементы через
`elements_stage`; фазы кадра и масштаба не вызываются (`test_edit_calls_neither_frame_nor_scale_stage`).

| Условие | Время правки |
|---|---|
| 100 проёмов, синтетический кадр `tests/test_ui_marks.VIEW`, контейнер разработки | 75 мс |

Бюджет теста — 1 с (`tests/test_ui_edit.py::EDIT_BUDGET_S`), запас ≈13× на медленную машину CI.
Покомпонентного кэша нет: он дал бы расхождение с полным пересчётом и обошёл бы глобальную
ветвь `reject` (`run.elements_stage`), которая снимает `meets_tolerance` со всех элементов сразу —
это проверяет `test_reject_branch_is_applied_after_every_edit`.

Во время перетаскивания двигается только рисунок; пересчёт — при отпускании кнопки.
Масштаб просмотра в момент отпускания становится масштабом точки: её σ следует за последним
действием оператора.
