# Обучение операторов

План 3, задача 24; спецификация, п. 13 («обучение операторов» — часть этапа 3) и п. 14
(«обучение до измерений»). Без обучения замеры σ клика (задача 25) и согласия
разметчиков (задача 26) измеряли бы кривую обучения, а не разметку.

## Программа

| Шаг | Что | Материал | Длительность (ориентир) |
|---|---|---|---|
| 1 | Прочитать инструкцию разметчика, особенно правила с пометкой **[человек]** | `docs/superpowers/specs/annotator-instruction.md` | 30 мин |
| 2 | Установка и первый запуск | `docs/operator-quickstart.md` | 15 мин |
| 3 | Разбор на синтетике с известной истиной вместе с инструктором: `python scripts/demo_ui.py --show`, затем тот же снимок руками («Начать разметку заново» в меню «Ещё»); сравнить свои числа с истиной | `demo_ui_out/` | 30 мин |
| 4 | Пробная разметка блоками до критерия (ниже) | `scripts/training_blocks.py` | 3–6 блоков по ~20 мин |
| 5 | Запись в журнал обучения | таблица ниже | — |

### Блоки

```bash
python scripts/training_blocks.py make --out-dir обучение --blocks 6
facade-digitize-ui --data-dir обучение --operator op-1a2b3c4d
```

Каждый блок — 3 синтетических фасада по 3 проёма разных размеров, под разными ракурсами,
с размытием и шумом (идеально резкая кромка учит кликать по тому, чего на реальных
снимках нет). Для каждого снимка:

1. открыть снимок; база — по подсказке `base_hint` из `блокNN/истина.json`
   (нижняя кромка самого левого проёма, её длина там же);
2. разметить три проёма и видимые грани откосов по инструкции;
3. «Выгрузить JSON и DXF» на шаге «Результат» — файлы лягут в `обучение/блокNN/экспорт/`.

Метка оператора (`--operator`) выдаётся исследованием и одна на человека на всё
обучение и замеры: по ней потом разбирается эффект обучения (п. 14). Имя не вводится.

```bash
python scripts/training_blocks.py score --out-dir обучение
```

печатает по блокам медиану времени на элемент и медиану |промаха| габарита против
истины, и решение по критерию.

### Критерий завершения

Обучение закончено, когда на **трёх последовательных блоках**:

- медианное время на элемент различается не более чем на **15 %** (наибольшее к
  наименьшему), и
- медианный |промах| габарита различается не более чем на **2 мм**.

Проверяется кодом: `facade_digitizer.training.converged`, тесты
`tests/test_training.py`. Минимум — три блока; меньше — критерий не выносится.

Стабилизация, а не порог: цель обучения — чтобы замеры задач 25–26 не зависели от
того, на каком по счёту блоке оператор, а не чтобы оператор «сдал экзамен». Промах
на синтетике сверх того виден в отчёте и сравнивается с σ в выходном файле: если
промах систематически больше σ, это повод разобрать с оператором правила
**[человек]** из инструкции, прежде всего клик в пересечение кромок.
