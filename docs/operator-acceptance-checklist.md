# Приёмка интерфейса оператора: чек-лист

Проходится **человеком в браузере** после установки по `docs/operator-quickstart.md`.
Автоматический прогон того же пути (`scripts/demo_ui.py`, тест
`tests/test_web_demo_script.py`) проверяет код, но не заменяет этот чек-лист: он не
видит, читается ли панель, удобно ли приближать и попадает ли рука в угол.

## Подготовка

```bash
python scripts/make_acceptance_inputs.py --out-dir data/приёмка
facade-digitize-ui
```

В `data/приёмка/` — снимки сценариев, два профиля и `ИСТИНА.txt` с размерами (в Docker
те же файлы уже лежат в `data/примеры/`). Проём на всех снимках фасада:
**1460 × 1900 мм, заглубление 150 мм**.

Отметка: ✅ — как ожидалось, ❌ — нет (записать, что увидели), — — не проверялось.

## А. Основной путь — `01_фасад.jpg`

| # | Действие | Ожидается | Отметка |
|---|---|---|---|
| А1 | Экран «Снимки» → карточка `01_фасад.jpg` | через несколько секунд кадр; шаг «Снимок ✓»; в сведениях размер, «поворот EXIF 1», доверие к плоскости; непригодная по углу часть кадра затемнена | |
| А2 | Панель шага «Снимок», блок «Качество снимка» | плашка `ok` или `degraded`, «Предварительный: до опорной базы», причины | |
| А3 | «Профиль камеры» → `профиль_DEMO-CAM.json` из списка (или «Загрузить…») | кадр пересчитан, в сведениях «калибровка по мишени» | |
| А4 | «Далее: масштаб», два клика по нижним углам проёма; длина 1460, Enter | σ масштаба в % и в мм на базе; окончательный вердикт; вкладка «Выровненный вид» доступна | |
| А5 | «Далее: проёмы» → «+ Окно»; приблизить до 2:1 (клавиша `2` или колесо), 4 угла в любом порядке | контур замкнут, синяя плашка постановки исчезла; подсказка, какие грани откоса видны; напоминание проверить тип кромки | |
| А6 | Кликнуть угол при масштабе мельче 2:1 | строка состояния подсвечена; под проёмами «грубее рекомендованного … мм» | |
| А7 | «Разметить откос» по видимой грани, 2 точки | голубая линия кромки | |
| А8 | Смотреть карточку проёма, затем «Далее: результат» | ширина ≈ 1460, высота ≈ 1900, заглубление ≈ 150 — **каждое с ± σ**, расхождение с истиной не больше σ | |
| А9 | На шаге «Проёмы» перетащить угол мышью | размер в карточке меняется сразу после отпускания | |
| А10 | Закрыть вкладку браузера; снова открыть адрес; карточка «В работе» | разметка, база и результат восстановлены | |
| А11 | «Выгрузить JSON и DXF» | в `экспорт/` рядом со снимком `.json`, `.dxf`, `.marks.json`, `.command.txt`; ссылки на панели скачивают их | |
| А12 | Открыть `.dxf` в CAD (AutoCAD, nanoCAD, LibreCAD, FreeCAD) | слои WINDOW, REVEAL, FACADE_EXTENT; размеры в мм; откос — на глубине по Z | |
| А13 | Выполнить команду из `.command.txt` в терминале с `--out-dir другой_каталог` | JSON совпадает с выгруженным побайтно (`fc /b` / `cmp`) | |
