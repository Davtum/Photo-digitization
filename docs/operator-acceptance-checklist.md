# Приёмка интерфейса оператора: чек-лист

Проходится **человеком в окне** после установки по `docs/operator-quickstart.md`.
Автоматический прогон того же пути (`scripts/demo_ui.py`, тест
`tests/test_ui_demo_script.py`) проверяет код, но не заменяет этот чек-лист: он не
видит, читается ли панель, удобно ли приближать и попадает ли рука в угол.

## Подготовка

```bash
python scripts/make_acceptance_inputs.py --out-dir acceptance_inputs
facade-digitize-ui
```

В `acceptance_inputs/` — снимки сценариев, два профиля и `ИСТИНА.txt` с размерами.
Проём на всех снимках фасада: **1460 × 1900 мм, заглубление 150 мм**.

Отметка: ✅ — как ожидалось, ❌ — нет (записать, что увидели), — — не проверялось.
