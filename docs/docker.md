# Запуск в Docker: интерфейс оператора в браузере

Всё приложение — в одном контейнере: окно работает на виртуальном экране внутри
контейнера и показывается **в браузере** (noVNC). Ставить Python, Qt и системные
библиотеки не нужно — только Docker.

## 1. Что нужно

- **Windows 10/11 или macOS** — [Docker Desktop](https://www.docker.com/products/docker-desktop/)
  (запустить и дождаться «Engine running»).
- **Linux** — Docker Engine и плагин `docker compose`.
- Около 3 ГБ на диске под образ.

## 2. Первый запуск

```bash
git clone -b feature/geometric-core-hyc1rc https://github.com/Davtum/Photo-digitization.git
cd Photo-digitization
mkdir data
docker compose up --build
```

Первая сборка — 5–10 минут (скачиваются Qt, OpenCV). Когда в консоли появится
`Интерфейс оператора: откройте в браузере http://localhost:6080`, откройте
**http://localhost:6080** — там окно программы. Работайте мышью и клавиатурой как
обычно.

При первом запуске в `data/примеры/` появятся снимки для проверки и `ИСТИНА.txt` с
правильными размерами (сценарии — `docs/operator-acceptance-checklist.md`).

## 3. Свои снимки и результаты

Папка `data/` рядом с `docker-compose.yml` — общая с контейнером (внутри это `/data`):

- **положите снимки** в `data/` (можно в подпапки) — в окне «Файл → Открыть снимок…»
  они сразу видны;
- **экспорт** («Файл → Экспорт JSON и DXF…») и **сессии** сохраняйте в `/data/…` —
  файлы появятся в `data/` на вашем компьютере; DXF открывается в CAD.

## 4. Автоматическая демонстрация

В `docker-compose.yml` поставьте `DEMO: "1"` и перезапустите — программа сама пройдёт
весь путь на синтетическом фасаде (база → проём → откос → расчёт → экспорт в
`data/демо/`), после чего окно останется для ручной работы.

## 5. Управление

| Что | Команда |
|---|---|
| остановить | `Ctrl+C` в консоли либо `docker compose down` |
| запустить снова (без пересборки) | `docker compose up` |
| обновить после `git pull` | `docker compose up --build` |
| в фоне | `docker compose up -d`, остановить — `docker compose down` |

Закрыли окно программы крестиком — через секунду оно откроется снова.

## 6. Настройки (`docker-compose.yml`)

- `RESOLUTION` — размер экрана в браузере, по умолчанию `1600x950x24`; для большого
  монитора — `1920x1080x24`. Масштаб подгоняется под окно браузера автоматически.
- `OPERATOR` — метка оператора `op-xxxxxxxx` для учёта трудозатрат (задача 22).
- Порт `6080` открыт только для этого компьютера (`127.0.0.1`): у экрана нет пароля.

## 7. Если что-то не так

| Симптом | Решение |
|---|---|
| Linux: «Папка /data недоступна для записи» | `sudo chown -R 1000:1000 data`, затем `docker compose up` |
| страница не открывается | дождаться строки «откройте в браузере…»; проверить, что порт 6080 не занят |
| серый экран в браузере | обновить страницу (F5) |
| Windows: `facade-start: not found` | клон сделан с CRLF-окончаниями и старый образ; `docker compose build --no-cache` |
| мелко/крупно | колесо мыши в окне кадра масштабирует снимок; `RESOLUTION` — размер экрана |
