# Оцифровка фасада: быстрый старт оператора

Интерфейс оператора работает **в браузере**: программа запускает сервер на этом
компьютере и открывает страницу. Открыть снимок фасада, задать масштаб, разметить
проёмы и откосы, получить размеры в миллиметрах **с погрешностью** и выгрузить
результат в JSON и DXF.

> **Проще всего — Docker**: `docker compose up --build` и открыть http://localhost:8765 —
> ставить Python не нужно (`docs/docker.md`).
>
> Демонстрация без своих снимков: `python scripts/demo_ui.py --show` — программа сама
> пройдёт весь путь на синтетическом фасаде с известными размерами и откроет браузер
> на размеченном снимке.

---

## 1. Установка

Нужен **Python 3.11 или новее** и исходники проекта (клон репозитория или архив).
Браузер — любой современный (Chrome, Edge, Firefox, Яндекс.Браузер).

### Windows 10/11

```powershell
# Python 3.11+ с python.org (галочка «Add python.exe to PATH»)
cd C:\путь\к\Photo-digitization
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -e ".[ui]"
```

Если PowerShell не даёт выполнить `activate`:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем повторить.

### Linux (Ubuntu/Debian)

```bash
sudo apt install python3.11 python3.11-venv libgl1 libglib2.0-0
cd ~/Photo-digitization
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[ui]"
```

### Запуск

```bash
facade-digitize-ui
```

Откроется браузер со страницей «Оцифровка фасада». Рабочая папка — `./data`
(другая: `--data-dir путь`). Второй запуск над той же папкой не поднимает второй
сервер, а открывает браузер на первом. Остановить — `Ctrl+C` в консоли.

### Метка оператора

Для исследования трудозатрат каждому оператору выдаётся непрозрачная метка вида
`op-1a2b3c4d` (не имя): `facade-digitize-ui --operator op-1a2b3c4d` или переменная
`FACADE_OPERATOR`. В выходном JSON у каждого элемента — `operator {id, edits, seconds}`,
в файле сессии — сводка: общее время, время при грубом масштабе, время на кадрах
`reject`, правки и отмены. Если открыть снимок, начатый другим оператором, программа
спросит, продолжить ли под своей меткой или начать заново.

## 2. Первый запуск на примере

```bash
python scripts/demo_ui.py --show
```

Скрипт рисует синтетический косой снимок фасада с одним окном 1460 × 1900 мм и
заглублением 150 мм и по шагам ставит базу, углы проёма и кромку откоса, считает,
сдвигает угол и выгружает. В конце печатает истину и измерение:

```
Истина сцены: 1460 × 1900 мм, заглубление 150 мм
Измерено:     1459.0 ± 14.2 × 1901.1 ± 14.8 мм, заглубление 157.2 ± 10.2 мм
```

Затем открывается браузер на этом снимке — дальше можно работать руками. Файлы — в
`demo_ui_out/`: снимок, сессия, выгрузка в `экспорт/`.

## 3. Экран «Снимки»

- **Перетащите снимок** в рамку вверху или нажмите «выберите файл» (JPG, PNG, TIFF).
  Он сохранится в `data/снимки/`. Тот же файл, уже лежащий в рабочей папке, не
  копируется — открывается прежняя работа.
- Ниже — все снимки рабочей папки (можно раскладывать по подпапкам) со статусом:
  **Новый**, **В работе**, **Выгружен**, **Изменён после выгрузки**.
- Щелчок по карточке открывает снимок. Работа **сохраняется сама** после каждого
  действия (`<снимок>.session.json` рядом со снимком) и при следующем открытии
  продолжается с того же места. Кнопки «Сохранить» нет.

## 4. Рабочий экран: четыре шага

Наверху — шаги **Снимок → Масштаб → Проёмы → Результат**: ✓ — сделано, ! — требует
внимания. Справа — панель текущего шага и одна главная кнопка «Далее». Слева — снимок.

**Что сделает клик по снимку, всегда написано в плашке над снимком.** Синяя плашка
«1/4 Кликните угол…» значит «сейчас ставятся точки»; «Закончить · Esc» — прекратить.
В остальное время клик ничего не ставит: перетаскивание двигает снимок, а за точку
можно взять мышью и перенести.

| Действие | Как |
|---|---|
| приблизить / отдалить | колесо мыши (под курсором) |
| точные масштабы | кнопки 1:2, 1:1, 2:1, 4:1 внизу или клавиши `5`, `1`, `2`, `4` |
| вписать снимок | «Вписать» или `0` |
| двигать снимок | перетаскивание (средняя кнопка или пробел + мышь — всегда) |
| закончить постановку точек | `Esc` |
| отменить последнюю точку проёма | `Ctrl+Z` |
| справка по клавишам | `?` |

Строка внизу показывает масштаб и **σ клика** при нём: у углов проёма приближайте до
2:1 и больше — при более грубом масштабе строка подсвечивается и пишет, сколько
миллиметров это стоит.

### Шаг 1. Снимок

Сведения о кадре (размер, поворот EXIF, камера), **профиль камеры**, **плоскость
фасада** и **предварительный вердикт качества** (`ok`, `degraded`; затемнена часть
кадра, непригодная по углу визирования).

- Если плоскость **не найдена** (мало линий, угол здания), сразу включается ручное
  задание: кликните четыре угла заведомого прямоугольника на стене (порядок не важен),
  выберите, что о нём известно — ширина и высота в мм, отношение сторон или «камера
  откалибрована», — и «Применить плоскость». Для снимка угла здания — «Обвести
  область» одной стены и «Оценить по области».
- Ручное задание доступно всегда: доверие к плоскости точности не гарантирует.

### Шаг 2. Масштаб

Кликните два конца отрезка известной длины в плоскости стены — как можно дальше друг
от друга (первый конец — начало координат) — и введите длину в мм; при наличии —
погрешность рулетки или дальномера. Масштаб считается сам, как только введена длина
(Enter или переход к другому полю). Концы можно перетаскивать; «Указать заново» —
поставить заново. Если первый конец — левый нижний угол фасада, отметьте это:
координаты будут от угла здания, охват — полный. Здесь же — **окончательный вердикт**
качества (`reject` — кадр отбракован по разрешению: размеры будут, признака допуска —
нет). После масштаба доступна вкладка «Выровненный вид» (только просмотр: клик по нему
показывает это место на снимке).

### Шаг 3. Проёмы

«+ Окно» или «+ Дверь» → четыре угла в любом порядке. В карточке проёма — установка
и **тип кромки** (от него зависит, выпускается ли признак допуска: новый проём берёт их
у предыдущего — проверьте), грань откоса (видимая камере выбрана сразу) и «Разметить
откос» → две точки по внутренней кромке. Размеры ± σ появляются в карточке сами.
Щелчок внутри контура выбирает проём; «Отменить точку», «Удалить» — в карточке.

### Шаг 4. Результат

Таблица: ширина, высота, положение, заглубление — **каждое с ± σ**; признак допуска —
с причиной, если его нет. Наведите на строку — проём подсветится. **«Выгрузить JSON и
DXF»** пишет в папку `экспорт/` рядом со снимком:

- `<снимок>.json` — модель фасада (схема 1.2);
- `<снимок>.dxf` — контуры в мм фасада, откосы на глубине (Z), σ — в XDATA;
- `<снимок>.marks.json` и `<снимок>.command.txt` — разметка и команда
  `facade-digitize`, которая воспроизводит тот же JSON без интерфейса.

Файлы можно скачать ссылками с панели. Меню «Ещё»: «Сохранить копию сессии…» (для
повторных разметок протокола точности клика), «Скачать файл сессии», «Начать разметку
заново» (прежняя сессия сохраняется рядом со снимком как `.bak`).

## 5. Профиль калибровки камеры (рекомендуется)

Без профиля фокусное расстояние берётся из таблицы моделей по EXIF, и условие
п. 2.2 «камера откалибрована» не выполнено — это видно в шапке результата.
Профиль делается один раз на камеру:

1. Распечатайте шахматную мишень (например, 10 × 7 клеток → 9 × 6 внутренних углов),
   наклейте на ровное основание, измерьте сторону клетки.
2. Снимите её **той же камерой и с тем же зумом**, что и фасады: 15–25 кадров под
   разными углами, мишень по всему полю кадра.
3. ```bash
   facade-calibrate папка_с_мишенью --board 9x6 --square-mm 25 --model "FC3411" --out профиль.json
   ```
   `--model` — ровно как в EXIF снимков фасада (иначе профиль будет отвергнут).
4. На шаге «Снимок» — «Загрузить…» (профиль сохранится в `data/профили/`) или выбор из
   списка; в CLI — `--profile профиль.json`. Лучше до разметки: смена профиля сдвигает
   кадр, и программа попросит подтвердить сброс точек. В сведениях появится
   «калибровка по мишени».

## 6. Если что-то не так

| Сообщение | Что делать |
|---|---|
| «Плоскость не восстановлена…» | ручная плоскость или область одной стены (шаг 1) |
| «Масштаб … грубее рекомендованного» | приблизить и перенести точку мышью |
| вердикт `reject` | размеры выпускаются, но без признака допуска; нужен снимок ближе или резче |
| красное «Сессия не сохраняется» | папка снимка недоступна для записи (OneDrive, права): «скачать» — сохранить сессию вручную; перенести снимок в рабочую папку |
| «одинаковое имя — переименуйте» | в папке `фасад.jpg` и `фасад.png`: файлы сессии и выгрузки совпали бы — переименуйте один |
| «Прежняя сессия не открылась…» | снимок изменён или подменён; прежняя сессия сохранена как `.bak` |
| профиль «не совпадает с моделью камеры» | профиль от другой камеры: сделайте свой |
| страница не открывается | посмотреть адрес в консоли (порт мог смениться, если 8765 занят) |

Приёмочный сценарий для проверки установки — `docs/operator-acceptance-checklist.md`.
