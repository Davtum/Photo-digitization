# Оцифровка фасада: быстрый старт оператора

Интерфейс оператора — настольное окно (PySide6): открыть снимок фасада, задать опорную
базу, разметить проёмы и откосы, получить размеры в миллиметрах **с погрешностью** и
выгрузить результат в JSON и DXF.

> Демонстрация без своих снимков: `python scripts/demo_ui.py --show` — окно само
> пройдёт весь путь на синтетическом фасаде с известными размерами и останется открытым.

---

## 1. Установка

Нужен **Python 3.11 или новее** и исходники проекта (клон репозитория или архив).

### Windows 10/11

```powershell
# Python 3.11+ с python.org (галочка «Add python.exe to PATH»)
cd C:\путь\к\Photo-digitization
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -e ".[ui]"
```

Если PowerShell не даёт выполнить `activate`:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем повторить.

### Linux (Ubuntu/Debian)

```bash
sudo apt install python3.11 python3.11-venv \
     libegl1 libgl1 libxkbcommon0 libxkbcommon-x11-0 libdbus-1-3 libfontconfig1 libxcb-cursor0
cd ~/Photo-digitization
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[ui]"
```

Без `libegl1` не импортируется `PySide6.QtWidgets` (ошибка про `libEGL.so.1`), без
`libxcb-cursor0` окно не открывается на рабочем столе X11 (ошибка про плагин `xcb`).

### Метка оператора

Для исследования трудозатрат каждому оператору выдаётся непрозрачная метка вида
`op-1a2b3c4d` (не имя): `facade-digitize-ui --operator op-1a2b3c4d` или переменная
`FACADE_OPERATOR`. В выходном JSON у каждого элемента — `operator {id, edits, seconds}`,
в файле сессии — сводка: общее время, время при грубом масштабе, время на кадрах
`reject`, правки и отмены.

### Проверка

```bash
facade-digitize-ui          # откроется пустое окно «Оцифровка фасада»
facade-digitize --help      # пакетный путь без окна
```

## 2. Первый запуск на примере

```bash
python scripts/demo_ui.py --show
```

Скрипт рисует синтетический косой снимок фасада с одним окном 1460 × 1900 мм и
заглублением 150 мм, открывает его в окне и по шагам ставит базу, углы проёма и кромку
откоса, считает, сдвигает угол и экспортирует. В конце печатает истину и измерение:

```
Истина сцены: 1460 × 1900 мм, заглубление 150 мм
Измерено:     1459.0 ± 14.2 × 1901.1 ± 14.8 мм, заглубление 157.2 ± 10.2 мм
```

Окно остаётся открытым — дальше можно работать руками. Файлы — в `demo_ui_out/`,
в том числе `facade_demo.session.json` (открывается через «Файл → Открыть сессию…»).

## 3. Работа со своим снимком

1. **Файл → Открыть снимок…** (`Ctrl+O`). Кадр обрабатывается несколько секунд:
   поворот по EXIF, снятие дисторсии (если есть профиль), оценка плоскости фасада.
   Зелёная подсветка — часть кадра, пригодная по углу визирования. Панель «Качество
   снимка» показывает **предварительный** вердикт.
2. **Плоскость.** Если оценка не удалась (угол здания, мало линий), окно само
   переключится в режим «Углы ручной плоскости»: укажите четыре угла заведомого
   прямоугольника на стене (порядок не важен) и одно доопределение — отношение
   сторон, два размера в мм или «камера откалибрована». Для снимка угла здания
   можно вместо этого обвести область одной стены («Обвести область оценки…»).
3. **Опорная база.** «Указать два конца базы…», два клика по концам известного
   размера (первый — начало координат), длина в мм, при наличии — погрешность
   рулетки/дальномера. Если первый конец — левый нижний угол фасада, отметьте это:
   координаты будут от угла здания, охват — полный. «Применить масштаб» — σ масштаба
   и **окончательный** вердикт качества появятся сразу.
4. **Проёмы.** Класс, установка, кромка → «Новый проём…» → четыре угла (порядок не
   важен). **Приближайте:** рекомендуемое увеличение у углов — не менее 2:1
   (колесо мыши; `Ctrl+1` — 1:1, `Ctrl+0` — вписать). При более грубом масштабе окно
   пишет, сколько миллиметров это стоит.
5. **Откос.** Окно подсказывает, какие грани видны камере. Выберите грань →
   «Указать внутреннюю кромку откоса…» → две точки по внутренней кромке.
6. **Посчитать.** Таблица «Результат»: ширина, высота, заглубление — каждое с ± σ;
   признак допуска — с причиной, если его нет.
7. **Правка.** В режиме «Навигация» (`Esc`) любую точку можно перетащить мышью —
   пересчёт мгновенный. «Отменить точку», «Удалить проём» — на панели.
8. **Сохранение.** «Файл → Сохранить сессию…» (`Ctrl+S`) — продолжить позже.
   «Файл → Экспорт JSON и DXF…» (`Ctrl+E`) — в выбранный каталог пишутся:
   - `<снимок>.json` — модель фасада (схема 1.2);
   - `<снимок>.dxf` — контуры в мм фасада, откосы на глубине (Z), σ — в XDATA;
   - `<снимок>.marks.json` и `<снимок>.command.txt` — разметка и команда
     `facade-digitize`, которая воспроизводит тот же JSON без окна.

## 4. Профиль калибровки камеры (рекомендуется)

Без профиля фокусное расстояние берётся из таблицы моделей по EXIF, и условие
п. 2.2 «камера откалибрована» не выполнено — это видно в шапке результата.
Профиль делается один раз на камеру:

1. Распечатайте шахматную мишень (например, 10 × 7 клеток → 9 × 6 внутренних углов),
   наклейте на ровное основание, измерьте сторону клетки.
2. Снимите её **той же камерой и с тем же зумом**, что и фасады: 15–25 кадров под
   разными углами, мишень по всему полю кадра.
3. ```bash
   facade-calibrate папка_с_мишенью --board 9x6 --square-mm 25 --model "FC3411" --out профиль.json
   ```
   `--model` — ровно как в EXIF снимков фасада (иначе профиль будет отвергнут).
4. Подключите профиль в окне — «Файл → Профиль калибровки…» (`Ctrl+K`) — или
   `--profile профиль.json` в CLI, лучше до разметки: смена профиля сдвигает кадр,
   и окно попросит подтвердить сброс точек. В шапке результата появится
   «K: target».

## 5. Если что-то не так

| Сообщение | Что делать |
|---|---|
| «Плоскость не восстановлена…» | ручная плоскость (шаг 2) или область одной стены |
| «Масштаб … грубее рекомендованного» | приблизить и переставить точку перетаскиванием |
| вердикт `reject` | размеры выпускаются, но без признака допуска; нужен снимок ближе или резче |
| «снимок … не тот, по которому сделана сессия» | файл снимка изменён или подменён — откройте исходный |
| профиль «не совпадает с моделью камеры» | профиль от другой камеры: сделайте свой |

Приёмочный сценарий для проверки установки — `docs/operator-acceptance-checklist.md`.
